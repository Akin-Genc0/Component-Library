## Form

The Form component provides a sign-in interface that adapts based on authentication state.

### Usage

```jsx
import Form from "@/components/form";

<Form />
```

### Features

- Container uses `neu-inset` styling
- Buttons use `neu-btn` class
- Shows signed-in state or sign-in form based on session
- Dark mode compatible

## Calendar

The Calendar component displays a monthly grid with navigation arrows and highlights today's date.

### Usage

```jsx
import Calendar from "@/components/calendar";

<Calendar />
```

### Features

- Month and year navigation with arrow buttons
- Highlights the current day with `neu-flat` styling
- Each day cell uses `neu-inset` for the pressed look
- Responsive grid layout with weekday headers

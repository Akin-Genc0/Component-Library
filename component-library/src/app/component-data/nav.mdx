## Navigation

The NewNav component provides a responsive navigation bar with icon, link, and button slots.

### Usage

```jsx
import NewNav from "@/components/newnav";

<NewNav
  hamburger
  navObj={[
    { type: "icon", label: "Logo", href: "/", iconPath: "...", slot: "left", viewBox: "0 0 256 256" },
    { type: "link", label: "Home", href: "/" },
    { type: "link", label: "About", href: "/about" },
    { type: "button", label: "Sign up", href: "/login", slot: "right" },
    { type: "icon", label: "Profile", href: "/login", imageSrc: "/user.png", slot: "right" },
  ]}
/>
```

### Props

| Prop | Type | Description |
|------|------|-------------|
| `hamburger` | `boolean` | Enable responsive hamburger menu |
| `navObj` | `NavItem[]` | Array of navigation items (icons, links, buttons) |
| `children` | `ReactNode` | Additional elements (e.g. ThemeToggle) |

### Features

- Nav bar uses `neu-flat` styling
- Sign-up button uses `neu-inset` 
- Mobile dropdown uses `neu-raised`
- Hamburger button uses `neu-btn`

# Security Policy

## Supported Versions

Only the latest published version of Looply receives security updates.

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Older releases | ❌ |

Users should update to the latest available version before reporting a vulnerability.

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Report potential vulnerabilities privately by emailing [looplygithub@gmail.com](mailto:looplygithub@gmail.com).

Please include:

- A clear description of the vulnerability
- The affected version or commit
- Steps to reproduce the issue
- The potential security impact
- Any suggested fix or mitigation, if known

You can expect an acknowledgement within seven days. The report will be reviewed, and you will be kept informed about its progress where possible.

Please allow time for a fix to be prepared and released before publicly disclosing the vulnerability.

# Contributing to Looply

Thank you for your interest in contributing to Looply!

Contributions such as bug fixes, new components, documentation improvements, accessibility improvements, and feature suggestions are welcome.

## Getting Started

1. Fork the repository on GitHub.

2. Clone your fork:

   ```bash
   git clone https://github.com/YOUR-USERNAME/Looply.git
   cd Looply
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

## Making Changes

1. Create a new branch:

   ```bash
   git checkout -b feature/your-change
   ```

2. Make your changes.

3. Test the project locally.

4. Run the project checks:

   ```bash
   npm run lint
   npm run build
   ```

5. Commit your changes with a clear commit message.

6. Push your branch and open a pull request.

## Contributing Components

When adding or updating a component:

- Use TypeScript.
- Follow the existing component structure and coding style.
- Make components responsive and accessible.
- Add or update the relevant documentation and examples.
- Export new components from the appropriate entry file.
- Avoid adding unnecessary dependencies.

## Reporting Issues

Before opening an issue, check whether it has already been reported.

When reporting a bug, include:

- A clear description of the problem.
- Steps to reproduce it.
- The expected and actual behaviour.
- Screenshots or error messages where helpful.
- Your browser and operating system, if relevant.

## Pull Requests

- Keep each pull request focused on one change.
- Clearly explain what you changed and why.
- Link any related issues.
- Update the relevant documentation.
- Make sure the project builds successfully before submitting.

## Code of Conduct

By contributing to Looply, you agree to follow the project's [Code of Conduct](CODE_OF_CONDUCT.md).
